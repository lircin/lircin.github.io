First run

  1. Unzip anywhere and run LIRCin.exe.
  2. Windows SmartScreen may warn that the app is from an unrecognised publisher (it is not code-signed yet). Choose More info → Run anyway.
  3. Add a network, join a channel. Type /help for commands.

Verify your download

Each release lists a SHA-256 checksum. In PowerShell: Get-FileHash LIRCin-*.zip

Activate Supporter / Pro

After supporting, you receive a key starting LIRC1-. In any chat window type /license YOUR-KEY. Keys are verified offline – the app never contacts a server to check them.

Beta builds store settings in %APPDATA%\LIRCin – back it up before upgrading.
