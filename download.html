First run

  1. Use the Setup wizard when provided, or unzip the portable package and run LIRCin.exe. No administrator access is required for a per-user installation.
  2. Windows may show a publisher warning for unsigned packages. Verify the source and checksum; a checksum confirms file integrity, not publisher identity. Do not install a self-signed certificate unless you deliberately choose a separately documented trust path.
  3. Add a suggested network or your own server, then join a channel. Type /help for commands.

Verify your download

Each release lists SHA-256 checksums. In PowerShell: Get-FileHash LIRCin-*.zip. Releases with a .sigstore.json bundle can also be verified with Cosign; this confirms that the file matches a signature from the published GitHub Actions workflow, but it is not Authenticode publisher signing:

cosign verify-blob --bundle LIRCin-1.1.0-beta.29-win-x64.zip.sigstore.json --certificate-identity "https://github.com/lircin/LIRCin-source/.github/workflows/release.yml@refs/tags/v1.1.0-beta.29" --certificate-oidc-issuer "https://token.actions.githubusercontent.com" LIRCin-1.1.0-beta.29-win-x64.zip

Activate Supporter / Pro

After purchase, paste the license key from your Gumroad receipt in Edition & upgrade and choose Verify Gumroad purchase online, or enter /license YOUR-KEY. Gumroad verification does not consume a use. The verified key is protected for your Windows account and remains usable offline. Manually issued signed LIRC1- keys also continue to work offline.

Beta builds store settings in %APPDATA%\LIRCin – back it up before upgrading.
