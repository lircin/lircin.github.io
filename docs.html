Compatibility

On networks and with users that don't run L'IRCin, nothing special happens: you get standard IRC. L'IRCin tags its realname with “[L'IRCin]”, and uses WHO to find peers – it does not send CTCP VERSION to strangers.

Troubleshooting

  • SmartScreen warning: the build isn't code-signed yet; choose More info → Run anyway.
  • Reset settings: close the app and rename %APPDATA%\LIRCin.
  • Bugs: open an issue with your version (/about).
